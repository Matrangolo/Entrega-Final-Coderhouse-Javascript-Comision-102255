# PetLab

Entrega final de JavaScript Coderhouse — Valentín Matrangolo.

PetLab es un simulador de tienda para mascotas. Nos permite buscar y filtrar productos, agregarlos al carrito, modificar las cantidades y confirmar los pedidos simulados.

## Cómo ejecutarlo?

1. Descargamos el repositorio.
2. Abrimos la carpeta del proyecto en nuestro editor.
3. Abrimos el archivo index con la herramienta del editor para navegadores (ejemplo Live Server).

Es necesario usar un servidor local para que fetch cargue el archivo productos.json . (SweetAlert2 requiere conexión a internet).

## Cuáles son las Funciones principales?

- Catálogo leído desde un archivo JSON.
- Búsqueda por nombre y filtro por categoría.
- Carrito con cantidades, eliminación de productos y cálculo del total.
- Persistencia del carrito y los pedidos mediante local storage.
- Confirmación de pedidos simulados e historial que se puede borrar.

En este simulador no se realizan pagos ni se envían pedidos reales.
